# Marwadi College of Engineering Website

A modern, responsive college website developed using HTML, CSS, Bootstrap 5, and JavaScript. The website presents college information, academic programs, program-specific outcomes, campus events, recruiter information, and contact details through a clean and professional user interface.

## Project Overview

The Marwadi College of Engineering Website is designed to provide visitors with an organized overview of the college. It features a modern homepage, responsive navigation, interactive course cards, an event gallery, and a detailed footer.

The project focuses on responsive web design, user-friendly navigation, visual consistency, and interactive elements.

## Features

- **Responsive Design:** Adapts to desktop, tablet, and mobile screen sizes.
- **Modern Hero Section:** Introduces the college with a prominent heading and navigation buttons.
- **Vision and Mission:** Displays the college's vision and mission statements.
- **Program Specific Outcomes:** Highlights technical expertise, innovation, and professional skills.
- **Courses Offered:** Presents engineering programs with duration information and interactive buttons.
- **Event Gallery:** Showcases Freshers Party, Graduation Ceremony, and Hackathons.
- **Recruiter Section:** Displays example recruiter names and their industry categories.
- **Smooth Animations:** Includes hover effects, scroll-based reveal animations, and smooth scrolling.
- **Interactive Navigation:** Provides section links and a responsive mobile navigation menu.
- **Course Details Modal:** Displays course information when a course button is clicked.
- **Contact Section:** Provides university contact information and an official website link.
- **Back-to-Top Button:** Allows visitors to return to the top of the page easily.

## Technologies Used



The website is implemented in a single HTML file containing the page structure, custom CSS, and JavaScript. External libraries, fonts, and images are loaded through online URLs.

## Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

Replace `YOUR-USERNAME` and `YOUR-REPOSITORY` with your GitHub username and repository name.

### 2. Open the Project Folder

```bash
cd YOUR-REPOSITORY
```

### 3. Run the Website

Open `index.html` in your preferred web browser.

Alternatively, open the project in Visual Studio Code and run it using the Live Server extension.

No backend server or database is required.

## Website Sections

Introduces the college with a large heading, supporting text, background photograph, and call-to-action buttons.

## Responsive Design

The website uses Bootstrap's responsive grid system and custom CSS media queries to support different screen sizes.

The navigation bar collapses on smaller screens, while cards and content sections adjust to the available width.

## Interactive Functionality

JavaScript is used to implement:

- Course details modal windows.
- Automatic copyright year updates.
- Mobile navigation menu behavior.
- Scroll-based reveal animations.
- Back-to-top button visibility and functionality.

## Customization

You can customize the website by editing `index.html`.

- Update the college information and descriptions.
- Change colors using the CSS variables defined in `:root`.
- Replace the image URLs with your preferred photographs.
- Add or remove course cards and gallery items.
- Update the contact information and social media links.
- Modify animations and responsive breakpoints.

# Important Notes

- An internet connection is required to load Bootstrap, Bootstrap Icons, Google Fonts, and externally hosted images.
- Course information and recruiter names are demonstration content and should be verified before official publication.
- Confirm contact information, social media URLs, and university details before deployment.
- This is a front-end project and does not include backend functionality, authentication, or database integration.
