🎓 Marwadi College of Engineering Website
A simple and responsive college website created using HTML5, Bootstrap 5, and CSS through Bootstrap utility classes. The project presents college information in a clean layout, with sections for the institution's vision and mission, program-specific outcomes, courses, event gallery, and recruiters.
✨ Features
- Responsive navigation bar with links to the main sections
- Welcome banner introducing Marwadi College of Engineering
- Vision and Mission sections describing the institution's goals
- Program Specific Outcomes (PSO) displayed in card layouts
- Courses Offered section featuring four engineering programs
- Event Gallery featuring Freshers Party, Graduation Ceremony, and Hackathons
- Top Recruiters section highlighting companies
- Bootstrap cards and grid layout for organized content
- Mobile-friendly navigation powered by Bootstrap's JavaScript bundle
🛠️ Technologies Used
- HTML5 — webpage structure
- Bootstrap 5.3.3 — responsive layout, navigation, cards, and styling
- Bootstrap Icons/Components: Bootstrap components are used; no separate icon library is included
- JavaScript (Bootstrap Bundle) — responsive navbar toggle

🚀 How to Run the Project
1. Clone or download this repository.git clone <your-repository-url>
2. Open the project folder.
3. Make sure the gallery images are in the expected location.
4. Open index.html in your web browser.
No build tools or backend server are required for this static website. An internet connection is needed to load Bootstrap from the CDN.

🎯 Project Purpose
This project demonstrates basic frontend web development skills, including semantic HTML structure, Bootstrap-based responsive design, navigation between page sections, and reusable card and grid layouts. It can serve as a beginner-friendly college website project or a foundation for adding more features.
